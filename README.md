# Live-Digi-Drum-Show
PP DEV

This is a passion project for Development course in 3th year Devine

I'm going to convert my acoustic drum to a digitized version with 11 piezo's and arduino were i can change the sound of each drum piece with an 11 potentiometer knobs/sliders board thru arduino and these things are going to adjust the live visuals in TouchDesigner that are project mapped on 3 different walls.

If you look to the branches you will have 3 branches:
* In the main branch you will find a short README with information about the project.
* In the arduino-tests branch you will find all the testings with arduino.
* In the dev branch you will find the final arduino code that is used for this project.
